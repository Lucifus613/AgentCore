Blob writes retain pending ancestor directory synchronization per resolved storage root across retries and store instances, clearing it only after a complete chain succeeds. Concurrent writes protect this process-local obligation without holding the lock during filesystem operations; existing roots without pending work still sync only through the root. Journal appends now decode the stored row for both first writes and identical retries, so returned payloads and blob references match records read back from the journal, including tuple payloads and empty media types.
